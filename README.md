## 常见问题

**注册要收费吗？**
不收费。注册、实名、推广素材、数据后台全部免费，无押金。

**号易的卡是物联卡吗？**
不是。号易上架的是四大运营商面向个人用户的正规号卡：本人实名、正规号段、支持通话短信。

**佣金怎么结算？**
秒返：激活充值达标后约 3-5 天到账；次月返：次月底 25-30 号左右。佣金状态「冻结中」自动转「已返佣」，APP 财务模块提现。

**有哪些推广红线？**
诱导下单、代充报销、二次包装、废单转单、涉诈订单——会被扣佣封号。如实介绍套餐是底线。
